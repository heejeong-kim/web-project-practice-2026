REQUIRED

모든 팀이 공통으로 완성하는 기본 서비스 범위

  • HTML·CSS 반응형 UI
  • JavaScript 상호작용
  • JSON 데이터 30건 이상
  • 검색 + 복수 필터 + 정렬

  • 사용자 테스트와 실제 배포

  • 로딩·실패·권한 오류 처리
  • 운영 환경에서 외부 서비스 검증
