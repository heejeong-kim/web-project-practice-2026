# 웹프로젝트 실습 · 2026학년도 2학기

강의교안, 팀 프로젝트 안내, 카공 실습 샘플을 제공하는 정적 웹사이트입니다.

- 사이트 주소: [웹프로젝트 실습](https://heejeong-kim.github.io/web-project-practice-2026/)
- 기술: HTML · CSS · JavaScript · JSON · LocalStorage
- 기본 트랙: 데이터 연결, 검색·필터·정렬, 상세보기, 개인화·비교함, 테스트, 배포
- 선택 심화: 외부 API, Google Sheets·Apps Script 등 공용 저장소 연결
- 문서 갱신: 2026-10-21 — 로컬 작업본 기준이며 공개 사이트 반영 여부는 별도 확인

## 강의 운영과 공개 범위

1–6주차는 수업 완료 자료로 유지합니다. 주차별 교안 진입 메뉴는 OT부터 15주차까지 제공하며, 9–15주차 본문은 비밀번호로 잠겨 있습니다. 2–5주차에 기존 적용된 일부 섹션 잠금은 별도로 유지합니다.

| 주차 | 진행 내용 |
| --- | --- |
| 7 | JSON 연결·출처와 실제/더미 구분·와이어프레임 점검 |
| 8 | 중간평가 — 1–6주차 범위 |
| 9 | 검색·필터·정렬, 와이어프레임 유지 |
| 10 | 이미지 제작·적용과 프로토타입 전환·상세 연결 |
| 11 | LocalStorage, 즐겨찾기·최근 본 공간·비교함·좋아요 프로토타입 |

| 13 | 발표자료 준비·마지막 수정·검토·리허설·발표 버전 확정 |

최종 IA 표는 **번호 · 화면 ID · 화면명 · 디스크립션(주요 구성요소·데이터·상태)** 네 열을 사용합니다.

## 주요 페이지

- 메인: `index.html`
- 강의교안: `lecture/index.html?week=07` 등 주차 파라미터로 선택
- 팀 프로젝트: `team-project.html`
- 카공 샘플: `data/samples/`의 주차별 폴더

## 폴더와 파일 역할

```text
web-project-practice-2026/
├─ index.html                    # 주차별 수업 목록
├─ team-project.html             # 팀 프로젝트 안내·등록
├─ lecture/index.html            # 교안 공통 화면
├─ asset/                        # 교안 이미지·카페 썸네일·히어로 배너
├─ css/                          # 교안·메인·샘플 공통 스타일
├─ js/
│  ├─ course.js                  # 주차 목록 화면
│  ├─ lecture.js                 # 교안 로딩·렌더링
│  ├─ local-data.js              # 파일 직접 열기용 데이터 로딩 보조
│  ├─ protected-lectures.js       # 9–15주차 비밀번호 입력·메모리 복호화
│  ├─ secure-sections.js          # 기존 일부 섹션 잠금
│  └─ cafe-*.js                  # 카공 이미지·스와이프·주차 안내 등
├─ data/
│  ├─ weeks.js                   # 주차 제목·요약·실습 샘플 연결
│  ├─ local-bundle.js            # 자동 생성 로컬 실행용 데이터 묶음
│  ├─ lectures/                  # 교안 원문 또는 암호화 교안 안내문
│  ├─ secure/                    # 잠금 설정·암호화된 교안/섹션
│  └─ samples/                   # 주차별 카공 샘플·실습 데이터·기존 예제
├─ tools/
│  ├─ build-local-data.py         # 로컬 데이터 번들 생성
│  └─ lock-lectures.cjs           # 교안 최초 암호화 도구
├─ start-local.command           # localhost:8000 서버 실행
└─ build-local-data.command      # 로컬 번들 재생성
```

`data/weeks.js`, `data/local-bundle.js`, `tools/`는 사용 중입니다. `local-bundle.js`는 직접 편집하지 않습니다.

- 7·9주차: 회색 와이어프레임과 이미지 X 박스 유지
- 10주차 이후: 실제 제작 이미지·상세 인터랙션·자동 스와이프 적용
- 메뉴: 7·9·10주차는 **홈 · 공간 · 마이**, 11–14주차는 **홈 · 공간 · 비교함 · 마이**
- 별은 개인 즐겨찾기, 하트·숫자는 좋아요 UI입니다. 현재 좋아요는 브라우저 프로토타입이며 실제 공용 집계가 아닙니다.
- API 미연동 공간에는 실시간 정보 안내 박스를 표시하지 않습니다. 정보 수정 제보는 작은 **작성하기** 버튼으로 엽니다.
- AI 생성 카페 이미지 40개와 히어로 배너를 사용합니다. 실제 매장 사진과 구분하며 제작 기록은 `asset/cafes/README.md`에서 관리합니다.

이전 공용 `data/samples/project/`는 현재 교안 연결 대상이 아닙니다. 실제 연결 기준은 `data/weeks.js`와 해당 주차 교안의 샘플 경로입니다.

## 로컬 실행

Python 3가 필요합니다. `start-local.command`를 실행하거나 프로젝트 루트에서 다음 명령을 사용합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. 암호화 교안과 외부 API 확인에는 localhost 또는 HTTPS 실행을 권장합니다.

파일을 더블클릭하는 `file://` 실행은 `data/local-bundle.js`를 이용합니다. 교안·암호화 데이터를 변경했다면 다음 명령 또는 `build-local-data.command`로 번들을 갱신합니다.

```sh
python3 tools/build-local-data.py
```

HTTP(S)에서는 교안과 암호화 파일을 직접 요청합니다. 파일 직접 열기와 배포본의 내용이 일치하도록 번들도 함께 갱신합니다.

## 9–15주차 교안 잠금

- 교안 본문은 AES-256-GCM으로 암호화하며 비밀번호 기반 키는 PBKDF2-SHA-256, 600,000회 반복으로 유도합니다.
- 암호문은 `data/secure/lecture-NN.enc.json`에 저장됩니다. `data/lectures/weekNN.md`에는 잠금 안내만 남습니다.
- 로컬 번들에도 잠금 안내와 암호문만 포함됩니다. 비밀번호와 복호화 본문은 브라우저 저장소에 보관하지 않습니다.
- **비밀번호 원문은 README·소스·설정·파일명·디렉토리명에 기록하지 않습니다.** 소유자가 별도로 보관합니다.
- 잠금 대상 Markdown에 평문을 넣으면 번들 생성기가 생성을 중단합니다.
- `tools/lock-lectures.cjs`는 최초 잠금 전용이며, 이미 암호화된 파일이 있으면 중단합니다. 일상적인 번들 갱신에 다시 실행하지 않습니다.
- 잠긴 교안을 수정하려면 소유자의 비밀번호로 복호화·편집·재암호화하는 별도 절차가 필요합니다. 안내문을 본문으로 덮어쓰지 않습니다.

잠금 범위는 웹뷰의 교안 본문입니다. 주차 제목·요약, 독립 실습 샘플, Notion 페이지의 접근 권한은 별도입니다. 이미 공개된 과거 배포본·저장소 이력은 현재 파일 암호화만으로 소급해서 비공개가 되지 않습니다.

## 배포와 확인

이 폴더는 GitHub Pages용 정적 사이트 작업본입니다. 로컬 수정은 공개 사이트에 자동 반영되지 않습니다.

배포 전에는 번들을 갱신하고 교안·암호문·공통 스크립트·스타일·샘플 변경을 함께 반영합니다. 배포 후 실제 HTTPS 주소에서 다음을 확인합니다.

1. 9–15주차는 잠금 화면으로 시작하며 올바른 비밀번호에서만 본문이 열리는지
2. PC·모바일에서 주차 이동, 공간 목록·상세 복귀, 즐겨찾기·비교함이 동작하는지
3. 이미지와 샘플 경로에 누락이 없는지
4. 외부 연동을 사용하는 경우 정상 응답·실패·대체 상태를 구분하는지

현재 로컬 파일 검사·기본 동작 검사와 암호화/복호화 검증은 수행했지만, 실제 공개 사이트의 최신 배포 및 PC·모바일 브라우저 최종 검증 완료를 의미하지는 않습니다.
