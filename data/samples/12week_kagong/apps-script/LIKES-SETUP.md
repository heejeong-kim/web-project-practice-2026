# 공용 좋아요 연결

1. 구글 스프레드시트에 연결된 Apps Script에 Code.gs를 저장하고 웹 앱으로 배포합니다. 실행 계정과 공개 범위는 운영자가 검토해 선택합니다.
2. /exec 주소를 웹뷰 루트 js/cafe-likes-config.js의 KAGONG_LIKES_URL에 입력합니다. likes 탭은 최초 조회 때 생성됩니다.
3. 서로 다른 두 브라우저에서 동일 공간을 좋아요하고 합계가 각각 반영되는지 확인합니다. 같은 브라우저의 반복 요청은 중복 가산하지 않습니다.
4. 미연결 시 JSON popularity에서 시작한 샘플 숫자를 이 브라우저 안에서 증감하는 프로토타입으로 동작합니다. 실제 공용 집계가 아니며 화면에 프로토타입용 예시임을 표시합니다. 연결 후 공용 합계는 실제 기록 0부터 시작합니다.
5. 즐겨찾기는 각 브라우저의 favorites에만 저장됩니다. 공용 좋아요는 브라우저의 임의 client ID로 중복 방지합니다. 로그인 사용자 인증·부정 요청 방지는 운영 서비스에서 별도 구현해야 합니다.
6. 익명 방문자 client ID를 초기화하면 기존 투표의 취소를 이어서 할 수 없으므로 일반 개인 저장 초기화에서는 like-client를 삭제하지 않습니다.
