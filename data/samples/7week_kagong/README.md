# 7주차 JSON·와이어프레임 전용 샘플

`7week_kagong.html`에서 홈, `pages/list.html`에서 JSON 목록을 확인합니다.
추천 영역은 수동 가로 넘김만 제공하며 히어로·썸네일은 X 박스입니다.
상세는 ID와 필드 출처를 점검하는 구조 예시이며 완성된 상세 인터랙션은 10주차에 연결합니다.
검색·필터·정렬은 9주차, 개인 저장·비교는 11주차, 외부 API는 12주차 선택 심화입니다.

현재 공간 데이터는 `data/items.json` 저장 파일에서 가져옵니다. `meta.source: api`는 향후 API 추가 대상이며 7주차에는 외부 API를 호출하지 않습니다. `meta.real`과 `meta.dummy`로 필드의 실제·실습 더미 범위를 구분합니다. 원본 제공기관·원본 URL·기준일·이용조건은 데이터 출처 기록과 함께 확인합니다.

배포 주소에서는 fetch를 사용합니다. 파일 직접 열기는 `items.js` 대체본을 사용하므로 JSON을 고쳤다면 대체본도 함께 갱신합니다. 1–6주차 샘플과 공용 `project/`는 유지합니다.
