이 도면에서 확인한 설계 판단

  • 화면 5개, 최대 3단계 — 홈 · 목록 · 상세 · 마이 · 마이 탭. Must 기능 5개가 모두 홈과 목록, 상세에 배치됨
  • 보조 사용자는 필터 값으로 수용 — 팀 프로젝트 모임 사용자를 위한 전용 화면 대신 noiseLevel과 seatType 값을 조건 더보기 안에 배치
  • 목록 카드 정보는 3개로 제한 — 모바일 세로 화면에서 한 번에 3건 이상 보이도록 배지를 콘센트·소음·영업 종료 시간으로 고정
  • 상세에서 목록 복귀 시 조건 유지 — 이 규칙이 지켜지지 않으면 목록과 상세를 반복 이동하는 2순위 문제가 그대로 남음
  • 화면 상태 6종을 모두 도면화 — 초기 · 결과 없음 · 오류 · 저장 완료 · 저장 없음 · 기본. 13주차 테스트 케이스의 정상·예외 기준으로 사용
  • 다음 단계 — 이 도면의 데이터 주석이 6주차 JSON 필드 명세가 되고, 영역 구획이 5주차 HTML 구조가 됨
