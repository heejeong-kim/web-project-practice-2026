### 4.2.1 실습 1｜필터 버튼 상태 변경
- 팀 화면의 필터 버튼을 클릭함
- 현재 선택된 버튼에 활성 클래스를 추가
- 단일 선택 조건이면 기존 활성 버튼에서 클래스를 제거
- 4주차 필터 설계가 복수 선택이면 클래스를 제거하지 않고 버튼별로 토글해 여러 조건이 동시에 유지되도록 함
- 콘솔에 현재 선택된 조건을 출력함
- 버튼에 사용한 값을 목록으로 기록(4.4에서 6주차 필터 허용값으로 사용)
---
### 4.2.2 실습 2｜검색어 읽기
- 검색 입력창의 값을 읽음
- 입력 이벤트가 발생할 때 현재 검색어를 확인
- 검색어 앞뒤의 불필요한 공백을 제거
- 아직 실제 필터링은 하지 않고 입력값이 정상적으로 들어오는지 확인
- 이 값을 어느 항목과 비교할지 정해 기록(4.4에서 6주차 검색 대상 필드로 사용)
---
### 4.2.3 실습 3｜보이기와 숨기기
- 상세 영역 또는 안내 영역을 기본적으로 숨김
- 버튼을 클릭하면 해당 영역을 표시
- 닫기 버튼을 클릭하면 다시 숨김
- CSS 클래스 변경을 이용해 화면 상태를 제어
- 여기서 만든 숨김 상세 영역이 10주차 상세보기의 컨테이너가 되므로 삭제하지 않고 유지
