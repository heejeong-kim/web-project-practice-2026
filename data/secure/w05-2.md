이번 주차의 카드는 JSON 없이 직접 작성했지만 그 내용이 곧 6주차 데이터 명세의 초안이 되므로, 실습을 마친 뒤 화면에 있는 값을 배열과 객체 형태로 정리해 두면 6주차에는 이 배열을 파일로 분리하는 작업부터 시작할 수 있음
### 4.4.1 카드 내용을 배열로 정리하기
```javascript
const items = [
  { id: 1, name: '', area: '', hasOutlet: true },
  { id: 2, name: '', area: '', hasOutlet: false }
];
```
- 필드명은 1.3에서 정한 HTML 클래스·id 이름을 그대로 사용
- 카드마다 중복되지 않는 id를 부여하고 HTML 카드에도 같은 값을 속성으로 연결
- 값이 비어 있더라도 항목 이름과 자료형은 정해 둠
- 위 예시의 필드명은 팀 프로젝트의 데이터 항목으로 바꿔 작성
