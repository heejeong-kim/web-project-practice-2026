#### 작업 폴더와 파일 만들기
화면을 작성하기 전에 파일을 놓을 자리를 먼저 만들고 브라우저에서 결과를 확인하는 방법까지 준비하며, 폴더 구조는 2.1.2 기준을 그대로 사용
- VS Code에서 File → Open Folder로 프로젝트 폴더를 열음
- index.html과 css, js 폴더의 파일을 생성하고 data와 images 폴더는 비어 있더라도 미리 만듦
- CSS는 head에서 link로, JavaScript는 body 끝에서 script로 연결
- 연결 확인은 CSS에 임시 배경색을 넣어 보고, app.js에 console.log를 한 줄 넣어 콘솔에 표시되는지 확인

#### 실습 절차
- 4주차 와이어프레임의 화면을 index.html로 옮김
- 영역별로 HTML 구조를 먼저 잡고 CSS로 배치를 정리
- 카드 2\~3건을 직접 작성해 구조와 여백을 확인
- 결과 없음 영역과 상세 영역을 숨김 상태로 추가
- JavaScript가 선택할 요소 목록을 표로 정리해 1장으로 남김
- 모바일 화면 폭에서 깨지는 영역이 없는지 확인
